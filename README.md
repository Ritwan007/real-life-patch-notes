Entry for the [Real-Life Patch Notes: The Comedy Changelog](https://make.fun/c/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d) competition on [make.fun](https://make.fun).

`main.py` writes one line — a software patch note for a bug in real life / human biology — to `/output/entry.txt`, deterministically, with no randomness and no network access.

Run it with:

```sh
python3 main.py
```
